Content management

Manage the homepage lineup.

Sign in with a GitHub access token to add, edit or remove the cars shown on the Autosphere Imports homepage. Changes are published straight to the live site.

Create a fine-grained token at github.com/settings/personal-access-tokens scoped to this repository with Contents: Read and write permission. The token stays in your browser — it is only ever sent to api.github.com.
